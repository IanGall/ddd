# Boot 模块协作说明

## 模块定位
- 本模块是启动装配根，负责 Spring Boot 启动、配置和基础设施组件装配。
- 应用用例、事务边界和跨聚合协作必须放在与 `domain` 同级的 `cases` 包。

## 变更边界
- 允许修改：启动配置、环境装配和运行时组件开关。
- 禁止修改：应用用例、领域规则和持久化实现。

## 依赖约束

- 依赖 `domain`、`trigger`、`infrastructure`，仅负责组合它们。
- 不在启动模块写入业务流程或持久化 SQL。
- Dubbo Provider 使用明文 Triple RPC，Nacos 注册中心凭据只允许由环境变量或 Secret 注入。
- 禁止提交生产凭据，也禁止记录认证附件。

## 提交前检查
- 核对用例流程是否完整、异常路径是否可追踪。
- 清理重复编排代码，避免出现 N+1 式远程调用。
