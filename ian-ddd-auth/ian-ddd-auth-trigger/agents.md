# Trigger 模块协作说明

## 模块定位
- 本模块作为入站适配层，处理 HTTP/RPC/MQ 等触发入口。
- 负责参数接收、可信上下文解析、API DTO 与领域对象转换，并调用领域服务或 Cases 服务。

## 变更边界
- 允许修改：Controller、消费入口、请求转换与返回包装。
- 禁止修改：核心业务编排、领域规则、基础设施实现。

## 依赖约束

- 依赖 `api`、`domain` 与入口适配所需的技术框架。
- 仅做适配与转换，不在入口层实现复杂业务逻辑。
- 不在 API DTO 增加通用 `accountId` 字段；HTTP/Dubbo 上下文由边界适配器建立并转换为显式领域 Actor，Cases 负责账号权限授权。
- Trigger 业务协作者只能是 `domain` 下的领域服务或同级 `cases` 下的用例服务。
- 可信上下文必须在入口层转换为显式 `cases.model.Actor`，禁止 Cases 直接读取 Context。

## 提交前检查
- 请求参数校验完整，错误码语义一致。
- 清理重复转换逻辑与未使用入口。
